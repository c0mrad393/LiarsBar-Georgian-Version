# მატყუარას ბარი 🍻 Liar's Bar (ქართული ვერსია)

ბლეფის კარტის თამაში რუსული რულეტით. ითამაშე ბოტებთან ან **მეგობრებთან ონლაინ**, მოსაწვევი ლინკით.

**▶ ითამაშე:** https://c0mrad393.github.io/LiarsBar-Georgian-Version/

## როგორ ვითამაშოთ მეგობრებთან

1. ჩაწერე სახელი, აირჩიე პერსონაჟი და დააჭირე **„ოთახის შექმნა“**-ს.
2. დააკოპირე მოსაწვევი ლინკი (`…/?room=abc123`) და გაუგზავნე მეგობრებს.
3. ისინი ლინკს ხსნიან, წერენ სახელს და ლობიში ჩნდებიან (მაქსიმუმ 4 მოთამაშე).
4. ცარიელ ადგილებზე შეგიძლია ბოტები დასვა. დააჭირე **„დავიწყოთ!“**-ს.

- თამაში Cloudflare-ის სერვერზე მიმდინარეობს, ამიტომ ნებისმიერ მოთამაშეს, host-ის ჩათვლით, შეუძლია გავიდეს და დაბრუნდეს.
- თუ მოთამაშე გავიდა, მის მაგივრად ბოტი თამაშობს. ლინკს ხელახლა თუ გახსნის, ადგილსა და კარტებს დაიბრუნებს.
  თუ host გავიდა, მისი უფლებები შემდეგ მოთამაშეზე გადადის.
- ინტერნეტი თუ გაწყდა, თამაში თავისით ხელახლა დაუკავშირდება.
- ვინც 30 წამი არ ითამაშებს, მის მაგივრად ავტომატურად დაიდება 1 კარტი. რულეტზე 15 წამი აქვს.

## წესები

- დასტაში 20 კარტია: 6 მეფე, 6 დედოფალი, 6 ტუზი და 2 ჯოკერი. ყველას 5 კარტი ურიგდება.
- მაგიდაზე ცხადდება ერთი კარტი: 🤴 მეფე, 👸 დედოფალი ან ⭐ ტუზი. **🃏 ჯოკერი ნებისმიერ კარტად ითვლება.**
- შენს სვლაზე დებ 1–3 კარტს პირით ქვემოთ და ამბობ, რომ ყველა მაგიდის კარტია. ბლეფიც შეიძლება 😏
- შემდეგ მოთამაშეს შეუძლია დაიყვიროს **„მატყუარა!“**. თუ ბლეფობდი, რევოლვერთან შენ ჯდები;
  თუ სიმართლეს ამბობდი, ბრალდების ავტორი ჯდება.
- რევოლვერში 6 ბუდეა და 1 ტყვია. ყოველი გადარჩენის შემდეგ შანსი უარესდება.
- თუ კარტი აღარ დაგრჩა და მაგიდაზე სხვისი კარტებია, უნდა დაიჭირო.
- იგებს ბოლოს დარჩენილი 🏆

რეჟიმს მთავარ მენიუში ირჩევ, ონლაინ თამაშში კი ლობიში.

## დეველოპმენტი

```bash
npm install
npm run server   # ოთახების სერვერი ლოკალურად: http://localhost:8787
npm run dev      # თამაში: http://localhost:5178 (ლოკალურ სერვერს უკავშირდება)
npm run sim      # 3000 თამაში ბოტებით: ძრავის შემოწმება
npm run online-test  # ორი ავტომატური მოთამაშე სერვერზე: ოთახი, ხელახლა შესვლა, მთელი თამაში
npm run build    # dist/index.html: ერთი ფაილი
```

`main`-ზე ყოველი push-ის შემდეგ GitHub Actions ჯერ სერვერს ტვირთავს Cloudflare-ზე, მერე საიტს აწყობს სერვერის
მისამართით და GitHub Pages-ზე აქვეყნებს. ამისთვის რეპოზიტორიას სჭირდება `CLOUDFLARE_API_TOKEN` და
`CLOUDFLARE_ACCOUNT_ID` secrets.

| ფაილი | რა არის |
| --- | --- |
| `src/engine.js` | თამაშის წესები და ბოტები. სუფთა ფუნქციები, React-ის გარეშე |
| `server/worker.js` | ოთახების სერვერი: Cloudflare Worker + Durable Object, ერთი ობიექტი ყოველ მაგიდაზე |
| `src/online.js` | სერვერთან კავშირი (WebSocket, ავტომატური ხელახლა დაკავშირება) |
| `src/useGame.js` | სოლო რეჟიმი (ძრავი ბრაუზერში) |
| `src/shared.js` | კლიენტისა და სერვერის საერთო კოდი |
| `src/ui/` | ეკრანები, ანიმაციები, ეფექტები |
| `src/ui/cards.jsx` | კარტები SVG-ში: ფიგურები, ჯოკერი, ეშმაკი, ზურგი |
| `src/i18n.js` | ყველა ტექსტი და ბოტების ხუმრობები |
| `src/sfx.js` | ხმის ეფექტები (Web Audio, ფაილების გარეშე) |

## უფასო ლიმიტები (Cloudflare Workers Free)

სერვერი ყოველ მაგიდას ცალკე Durable Object-ში ატარებს. თამაშის დროს მაგიდა მეხსიერებაშია, ლობიში კი „იძინებს“.
დღიური ლიმიტი განახლდება 00:00 UTC-ზე (თბილისით 04:00).

| რესურსი | უფასო დღიური ლიმიტი | ჩვენი ხარჯი |
| --- | --- | --- |
| Durable Object-ის დრო | 13 000 GB-s (128 MB × ~28.9 საათი) | **მთავარი შეზღუდვა:** ~28 საათი აქტიური თამაში დღეში, ყველა მაგიდა ერთად |
| მოთხოვნები | 100 000 | ~10–30 ერთ თამაშზე (WebSocket-ის შეტყობინებები 20:1-ზე ითვლება) |
| ბაზაში ჩანაწერები | 100 000 სტრიქონი | ~10–20 ერთ თამაშზე (მხოლოდ რაუნდის დასაწყისში) |

ერთი თამაში საშუალოდ 5–7 წუთია, ანუ **დღეში დაახლოებით 250–300 თამაში**. ერთდროულ მაგიდებზე ცალკე შეზღუდვა არ არის:
ლიმიტი დღიური ჯამია. სოლო რეჟიმი ბოტებთან სერვერს საერთოდ არ იყენებს.
