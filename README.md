# მატყუარას ბარი — Liar's Deck (ქართული ვერსია)

ბლეფის ბარათის თამაში რუსული რულეტით: შენ + სამი ბოტი (სკაბი, ფოქსი, ტოარი).

**▶ ითამაშე ონლაინ:** https://c0mrad393.github.io/LiarsBar-Georgian-Version/

## გაშვება ლოკალურად

უბრალოდ გახსენი `index.html` ბრაუზერში (ორჯერ დაწკაპუნება). სერვერი არ სჭირდება,
მხოლოდ ინტერნეტი: React, Babel და Tailwind CDN-იდან იტვირთება.

## ფაილები

| ფაილი | რა არის |
| --- | --- |
| `LiarsDeckPro.jsx` | თამაშის კოდი (ერთი React კომპონენტი). Claude Artifact-ში პირდაპირ ჩასვამ. |
| `index.html` | გასაშვები გვერდი: შიგნით უკვე ჩაშენებულია `LiarsDeckPro.jsx` |
| `build.mjs` | `LiarsDeckPro.jsx`-ს `index.html`-ში ჩააშენებს |

`LiarsDeckPro.jsx`-ის შეცვლის შემდეგ გაუშვი:

```bash
node build.mjs
```

შემდეგ commit + push. GitHub Pages დემო ავტომატურად განახლდება.
